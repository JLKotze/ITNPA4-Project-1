# ITNPA4 Project

## Project Overview
This repository contains the work completed for Questions 1–4 of the ITNPA4 project.

## Repository Structure

- Documentation: Project documentation for Questions 1–4.
- Datasets: Datasets used throughout the project.
- Notebooks: Jupyter Notebooks demonstrating the analytical workflow for each question.
- Deployment: Deployment instructions and application files for Question 2.3

## How to Use This Repository

1. Clone or download the repository.
2. Refer to the Documentation folder for the project reports.
3. Open the Notebooks folder to view the analytical workflows.
4. Refer to the Deployment folder for instructions on running the applications.
